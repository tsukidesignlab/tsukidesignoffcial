首頁/作品實驗室/Wormy Planty
PROJECT 03 / SUSTAINABILITY

Wormy Planty

從校園廚餘，長出一堂生動的自然課。

校園循環教育系統概念設計校園教育資源循環產品設計

以蚯蚓堆肥與校園種植串聯食物殘渣、碎紙與土壤循環，讓孩子透過實作理解資源再利用。

PROJECT VISUAL / TSUKI DESIGN LAB
01 / DESIGN QUESTION / 問題洞察

我們看見的問題

校園裡每天都會產生食物與紙類剩餘物，但資源回收的後續去向，對孩子而言未必容易看見。

02 / DESIGN CONCEPT / 設計概念

讓想法變得可參與

透過可觀察、可參與的堆肥與種植過程，讓抽象的循環概念成為日常體驗。

03 / DESIGN PRACTICE / 設計過程

從概念到原型的實踐

整合設備形態、教育情境與使用流程，探索兒童可理解的堆肥操作方式。

04 / PROJECT STATUS / 目前階段

持續探索與驗證

為教育系統設計提案，實際導入仍需衛生、安全、維護與場域測試。

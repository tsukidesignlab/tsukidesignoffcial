PROJECT 05 / SUSTAINABILITY

EnviroTrack Card

讓每一次入住，都更看得見自己的環境影響。

旅宿永續互動服務概念設計旅宿體驗服務設計ESG

結合實體卡片、旅宿介面與碳足跡資訊，探索如何在住宿體驗中促進節能與永續消費。

PROJECT VISUAL / TSUKI DESIGN LAB
01 / DESIGN QUESTION / 問題洞察

我們看見的問題

旅客在住宿期間使用的能源與資源，通常難以直觀理解，也較少與日常選擇建立連結。

02 / DESIGN CONCEPT / 設計概念

讓想法變得可參與

以實體卡片連結旅宿服務介面，將難以感受的資源消耗轉化成可看見的回饋。

03 / DESIGN PRACTICE / 設計過程

從概念到原型的實踐

規劃旅宿使用流程、資訊介面與獎勵互動，探索服務設計導入可能性。

04 / PROJECT STATUS / 目前階段

持續探索與驗證

為產品服務概念，數據量測、設備整合與獎勵機制仍需實地驗證。

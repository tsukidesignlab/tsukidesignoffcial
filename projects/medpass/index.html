PROJECT 06 / SERVICE INNOVATION

MEDPASS

讓人在陌生的地方，也能更有方向地尋求協助。

旅外就醫資訊服務概念概念設計UX / UI旅外就醫服務設計

針對海外就醫的語言、資訊與保險流程障礙，規劃整合醫療資訊與翻譯支援的數位服務概念。

PROJECT VISUAL / TSUKI DESIGN LAB
01 / DESIGN QUESTION / 問題洞察

我們看見的問題

人在海外生病時，可能同時面對語言不通、不熟悉醫療制度與保險流程複雜等挑戰。

02 / DESIGN CONCEPT / 設計概念

讓想法變得可參與

把醫療資訊查找、語言支援與保險需求整理成較直覺的服務路徑。

03 / DESIGN PRACTICE / 設計過程

從概念到原型的實踐

從旅客旅程、資訊架構與手機介面進行系統整合設計。

04 / PROJECT STATUS / 目前階段

持續探索與驗證

目前為服務及介面概念，非已正式提供的醫療診斷或保險服務。
